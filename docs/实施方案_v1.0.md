# 财报研读 Agent — 实施方案 v1.0

> 定稿日期：2026-10-17 ｜ 适用代码：`backend/` + `frontend/`
> 本文是接下来所有改动的**唯一依据**。与旧文档冲突时以本文为准。

## 0. 一句话目标

把"能查数、能对话"的 demo，推进到**"算得对、答得准、查得到出处"**的可用工具：

1. 数据边界明确（支持哪些指标、哪些明确不支持）
2. 结果可自动验证（200 条真值集 + 基线门禁）
3. 回答带溯源（每个数字可回指期次/指标/单位）
4. 分析有产出（杜邦、三表勾稽异常、同行对比）

## 1. 非目标（明确不做，防止范围膨胀）

| 不做 | 理由 |
|---|---|
| 报告 8 章 / 数字白名单 / docx | 缺官方文字材料（PDF/公告），做了只是数值散文 |
| MCP 协议接入 | 需前置服务与评测垫底，当前瓶颈不是工具数量 |
| 多 agent 协作 | 同上；先把单 agent 的"准"做出来 |
| L1 人工真值集（50~100 家） | 40~90 人时，个人项目不划算；用 L3 自动真值替代 |
| `query_sql` / `describe_schema` 工具 | 与 typed tool 重复，且打开 SQL 攻击面 |
| RAG 重启 / 向量化 | 没有原文语料前，评它没有意义 |
| 前端图表（ECharts） | 等 M-C 有服务出数后再做，避免空转 |

## 2. 里程碑

### M0 数据边界（约 1 天）

**做什么**
- 三张映射表扩容：资产负债表 14 → 34、利润表 18 → 28、现金流量表 4 → 16
  清单从 `storage/raw/` 的真实列名中挑选（不猜列名），优先"分析必需"科目：
  有息负债（短期借款/长期借款/应付债券）、研发费用、税金及附加、投资收益、
  少数股东权益、在建工程、无形资产、合同负债、销售收现、购货付现、支付税费、
  借款/偿债现金、利息支付、期末现金。
- `metric_dict` 补对应条目（`name_cn` / `aliases` / `unit_type`）
- 宽表 `financial_core` 补列（模型 + 迁移清单双写，保证老库自动补列）
- `replay` 全量重建 20 家（不联网）
- 16 个空列分三类处置：补公式（7）/ 标"需外部数据"（4）/ 标"不支持"（5）
- 产出**能力清单** `docs/指标能力清单.md`（自动生成，列出支持/不支持）

**验收**
- 宽表有效指标 ≥ 100（当前 59）
- 无悬空列（每列要么有映射源、要么有 formula、要么在"不支持"名单里）
- L0 全绿（回算/同比/单位/长宽一致/覆盖）

### M-A 可验证（约 1.5 天）

**做什么**
- **trace-lite**：`GET /api/agent/trace?session_id=` 读 `conversations.meta_json`，
  返回每轮的 `tools_called / steps / stop_reason / clarify / elapsed_ms`
- **L3 自动真值评测** `scripts/eval/`：
  - `build_dataset.py`：从库中抽样 200 条 `(公司, 指标, 期次)`，用 SQL 算真值写 `datasets/l3_queries.jsonl`
  - `run_l3.py`：逐条走**服务层**（不是 LLM），比对返回值与真值
  - `baseline_v1.json`：记录基线；任一指标下降 → 退出码 1
  - `pytest -m eval` 可运行
- 指标定义：`l3_exact_match`（数值完全一致）、`l3_unit_ok`（单位归一后一致）、`l3_coverage`

**验收**：`python -m scripts.eval.run_l3` 输出 pass rate 并写出 baseline；改错一条 SQL 能立刻红灯。

### M-B 可解释（约 1.5 天）

**做什么**
- `domains/financial/services/resolver.py`：`resolve_metric(text)` / `resolve_company(text)`
  基于 `metric_dict`（name_cn + aliases）与 `company_master` 的词典匹配；
  返回 `{code, confidence, candidates, matched_by}`，**低置信返回候选而不是猜**
- `domains/financial/services/quote.py`：`quote(company, metric, period)` →
  `{value, unit, display, period, metric, is_estimated, source}`（工具与溯源共用）
- 工具 `query_financials` 返回值增加 `data`: `[{label, metric, period, value, display, unit, estimated}]`，
  LLM 可读同一份数据，前端也能直接渲染
- `scripts/eval/run_l2.py`：读 `datasets/l2_queries.jsonl`（50~100 条真实问法），
  评 Top-1 / Top-3 / 低置信是否正确返候选
- 前端：数字以卡片/表格呈现，可展开看来源

**验收**：L2 Top-1 ≥ 85%；回答里的数字与 `data` 完全一致（不靠模型复述）。

### M-C 洞察（约 2 天）

**做什么**
- `services/dupont.py`：`ROE = 净利率 × 总资产周转率 × 权益乘数`，**同源重算三因子再相乘**，
  与报表 ROE 差 > 1pp 标注；返回因子明细与加总校验
- `services/anomaly.py`：三表勾稽三式（应收 vs 营收、存货 vs 成本、经营现金流 vs 净利）
  + 同比偏离阈值；每条异常带 `evidence`（指标/期次/值/基线），**无 evidence 不出结论**
- 工具：`dupont_analysis` / `detect_anomalies` / `compare_peers`（薄封装，只做参数与呈现）
- 前端：分析结果卡片（杜邦三因子、异常清单）

**验收**：杜邦三因子乘积与 ROE 差 < 0.1pp；每条异常可复现；工具全部注册且被 LLM 正确选用。

## 3. 最终目录与职责

```

│   ├── flow.py                   节点/边/路由器/扇出 + 事件
│   ├── loop.py                   预算 / 指纹 / 停止原因
│   ├── invoke.py                 工具统一入口（校验/重试/熔断/结构化错误）
│   ├── llm.py                    OpenAI 兼容客户端
│   ├── registry.py               工具注册表
│   ├── memory.py                 会话窗口 + 摘要
│   ├── store.py                  会话落盘（SQLite）
│   └── state.py                  流程共享黑板
├── domains/
│   ├── conversation/             对话（策略）
│   │   ├── loop.py               assemble → decide → act → answer
│   │   └── graph.py              入口单例
│   ├── financial/                财报数据域
│   │   ├── models.py db.py repository.py      表 / 引擎迁移 / CRUD
│   │   ├── formula.py display.py              公式求值 / 单位展示
│   │   ├── fiscal_calendar.py industry_scope.py
│   │   ├── quality.py corpus.py               L0 校验 / 检索语料
│   │   ├── services/             ★ 分析服务（不注册给 LLM 的计算逻辑）
│   │   │   ├── resolver.py       中文名 → 指标/公司（低置信返候选）
│   │   │   ├── quote.py          取数 + 单位归一 + 溯源字段
│   │   │   ├── dupont.py         杜邦三因子（同源重算）
│   │   │   └── anomaly.py        三表勾稽 + 偏离
│   │   ├── ingest/               eastmoney.py（采集）/ mapping.py（映射归一）
│   │   └── tools/                注册给 LLM（文件名 == 工具名）
│   ├── retrieval/                向量检索（暂冻结）
│   └── report/                   报告（暂不挂主图）
├── interfaces/http/              FastAPI 路由与 schema
└── platform/                     settings / embedding

backend/scripts/
├── fetch_slice.py                拉数 + 窗口清理
├── seed_metric_dict.py           指标字典
├── ...                           巡检脚本
└── eval/                         ★ 评测
    ├── build_dataset.py          L3 真值集生成
    ├── run_l3.py                 L3 结果集比对
    ├── run_l2.py                 L2 口径解析
    ├── datasets/                 l2_queries.jsonl / l3_queries.jsonl
    └── baselines/baseline_v1.json
```

**分层纪律**（不遵守会在 review 时退回）
1. `harness` 不 import `domains`
2. `services` 不 import `tools`（工具是服务的消费者，不是反过来）
3. `repository` 只做读写；计算进 `services`；纯算术进 `formula`
4. 每个工具文件只做：解析参数 → 调服务 → 组织返回（不写业务规则）

## 4. 两条数据流

**一次问答**
```
HTTP → routes.agent → conversation.loop
  assemble（system + 记忆 + 工具 schemas）
  decide（LLM：工具 / 回答 / ask_user）
  act（invoke.run_tool → tools.* → services.* → repository）
  answer（收口 + meta）
→ {agent, reply, clarify, options, data} → 前端渲染（数字与 data 一致）
```

**一次评测**
```
build_dataset.py（抽样 → SQL 真值 → jsonl）
  → run_l3.py（走 services.quote 取数 → 比对 → pass_rate）
  → baseline_v1.json（门禁：低于基线 → exit 1）
```

## 5. 接口契约

**对话响应（`POST /api/agent/chat`，SSE 的 `result` 事件同构）**
```jsonc
{
  "agent": "财报解读助手",
  "reply": "……",
  "clarify": false,
  "options": [],
  "data": [                                  // M-B 新增：数字一律由此渲染，模型不搬运
    {"label": "毛利率", "metric": "gross_margin", "period": "2025Q1",
     "value": 0.9211, "display": "92.11%", "unit": "ratio", "estimated": false}
  ],
  "meta": {"tools_called": ["query_financials"], "steps": 2,
           "stop_reason": "answered", "elapsed_ms": 3120}   // 仅 /trace 返回
}
```

**服务签名（services 层）**
```python
resolve_metric(text: str) -> Resolution      # {code, confidence, candidates, matched_by}
resolve_company(text: str) -> Resolution
quote(company: str, metric: str, period: str | None) -> Quote | None
    # Quote: {metric, label, period, value, unit, display, estimated, source}
dupont(company: str, period: str) -> Dupont  # {roe, net_margin, asset_turnover, equity_multiplier, check}
detect_anomalies(company: str, periods: int = 4) -> list[Anomaly]
    # Anomaly: {rule, metric, period, observed, baseline, delta, evidence}
```
